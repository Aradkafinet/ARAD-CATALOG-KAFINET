راهنمای استفاده در GitHub
==========================

ساختار این بسته:
- catalog_aradcinema_synced.html
- posters/   (پوسترها با نام عنوان فیلم)

برای GitHub:
1) فایل HTML و پوشه posters را در یک پوشه/Repository قرار دهید.
2) مسیرها را تغییر ندهید؛ HTML از مسیر نسبی posters/ استفاده می‌کند.
3) برای GitHub Pages، همین فایل HTML را به عنوان صفحه اصلی یا index.html قرار دهید.

نکته:
نام فایل هر پوستر بر اساس عنوان انگلیسی موجود در کاتالوگ تنظیم شده است. مواردی که چند فایل تکراری داشتند، یک نسخه با کیفیت بهتر انتخاب شده است.
